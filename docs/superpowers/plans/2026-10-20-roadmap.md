## Cross-plan contracts (fixed here; later plans consume them)

**Tokens (RS256 JWT).** Claims: `iss`, `aud`, `sub` (user id), `tenant`, `role`, `scope`
(space-separated), `client_id` (optional), `exp`, `iat`, `jti`. Helpers live in
`packages/shared/src/northstar_shared/tokens.py`: `mint_token(...)`, `verify_token(...)`.
Audiences: Public API = `northstar-public-api`; MCP server = `northstar-mcp` (M2+).
In M3 the IdP adds RFC 8693 token exchange: an MCP-audience token is exchanged for an
API-audience token *for the same user*. The MCP server never holds a tenant-wide credential.

**Roles.** `ops_rep`, `carrier_sales`, `pricing`, `ops_manager`, `broker_admin`.
The Public API's RBAC matrix (M1, `apps/mock_tms_api/src/mock_tms_api/rbac.py`) and the MCP
server's tool policy (M2) are written **independently**. Neither imports the other. This is
what lets M7 show that a deliberately broken MCP policy is still stopped by the API.

**Public API v1 endpoints (M1).** These are the only way MCP tools reach data:
`GET /v1/loads`, `GET /v1/loads/{id}`, `GET /v1/loads/{id}/events`,
`POST /v1/loads/{id}/book` (requires an `Idempotency-Key` header),
`GET /v1/carriers/{dot}`, `GET /v1/carriers/{dot}/compliance`,
`GET /v1/carriers/{dot}/scorecard`, `GET /v1/capacity`,
`GET /v1/lanes/{orig}/{dest}`, `GET /v1/rates/index`, `GET /health`,
and quotes CRUD with explicit operationIds (consumed by the M2 OpenAPI bridge):
`POST /v1/quotes` (`create_quote`), `GET /v1/quotes` (`list_quotes`),
`GET /v1/quotes/{quote_id}` (`get_quote`), `PATCH /v1/quotes/{quote_id}` (`update_quote`,
requires `If-Match: <version>`), `POST /v1/quotes/{quote_id}/withdraw` (`withdraw_quote`,
a soft delete that can be reverted with `update_quote` status=draft). The OpenAPI document is served at `/openapi.json`.
Not found and not in your scope return the same response: 404 `{"error":"NOT_FOUND"}`.
A missing permission returns 403 `{"error":"FORBIDDEN","required":"<perm>"}`.

## Carry-forwards from M0+M1 (read before writing the M2 plan)

- **The OpenAPI 422 schema drifts from runtime.** The API returns `{"error":"VALIDATION_FAILED","fields":[...]}`, but `/openapi.json` still advertises FastAPI's default 422 schema. The M2 OpenAPI bridge must not trust the error schemas in the spec; override them in the API or in the bridge.
- **Auth uses a second pooled connection.** `current_principal` checks `tms.users` on its own connection. Every route must declare its principal *before* `conn: Conn`, or concurrent requests can deadlock the pool (max 10). Consider sharing the connection or caching the lookup.
- **"Late today"** for broker_a returns 6001 plus about 10 random late loads. Evals and the demo derive expected answers from the DB, never assume 6001 is the only one.
- **`is_fictional`** is exposed on carrier profiles. The MCP tool output schema should drop it.
- **Unknown `market` on `/v1/rates/index`** returns an empty 200. The MCP layer should present this as "no rates for that market", not "rates are zero".
- **Withdrawn quotes** can still have their rate, date or notes patched. Decide the semantics before the bridge exposes `update_quote`.
- **Token `scope` is not enforced** by the API, and `aud` lists are rejected (`Claims.aud: str`). Revisit both in M3 (token exchange, RFC 8707).
- **Keys volume shortcut:** the API can read the private key. M3 gives the IdP its own key volume.
- **Demo refresh:** `docker compose run --rm -e FORCE_RESEED=1 init`. Run it right before a demo so the 20-minute and 6-hour ping contrast (4521 vs 6002) is fresh.
- **Deferred minor findings** (test strength, small duplications) are tracked in git history and the final-review notes. None block M2.
